# CS601_HW2_Johnson



To get this project to work via local hosting I used Express. To do the same follow these steps in the terminal. 
1. node -e "require('child_process').execSync('npm init -y', {stdio: 'inherit'})"type npm init -y
2. node -e "require('child_process').execSync('npm install express', {stdio: 'inherit'})"
3. node server.js
3 ctrl + click on the localhost:3000

Otherwise for testing purposes you can run through the HTml file if local hosting is not required at the time.
